# 0.5.5 — безшовний фон та один острівець

- Нижній край фото «Атмосфери» має окрему плавну маску прозорості. Під ним проявляється справжній градієнт фону, тому різниця між плоским кольором затемнення та градієнтом більше не утворює жорстку межу.
- У новому стилі є один екземпляр острівця вкладок. При закріпленні він переноситься з профілю до місця в системній панелі, а при зворотній прокрутці повертається. Ширина, компонент і вибір залишаються тими самими.
- Прибрано додаткову спільну скляну підкладку UIBarButtonItem навколо сегментованого контролу.

Зміни коду перевірено локально; компіляція й пакування IPA — у GitHub Actions. Візуальна перевірка на iPhone ще потрібна.
