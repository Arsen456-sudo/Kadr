# 0.5.4 — головна вкладка «Атмосфери»

Зміни стосуються лише оформлення «Атмосфера».

- Початкова вкладка «Профіль» показує локальну статистику, спільноту, бібліотеку, налаштування й оформлення. На чужому профілі приватні пункти не показуються.
- Публікації винесено в окрему вкладку: дві рівні колонки, заокруглені превʼю, підписи та кількість фото в альбомі. Відтворення починається тільки після відкриття.
- Колір фону обчислюється з нижньої частини фото через Core Image. Фото розчиняється в цьому кольорі; панелі головної вкладки використовують матове розмиття й слабкий світлий відтінок без Liquid Glass.
- Вкладки мають однаковий компонент і контекст системної панелі до й після закріплення. Вони зберігають ширину та розташовуються між верхніми круглими кнопками. Заголовок «Профіль» при закріпленні відʼїжджає вгору.
- «Вийти» замінено системною іконкою з доступною назвою дії; іконки круглих дій зменшено на 2 пункти. Маску нижнього блюру піднято на 3 пункти.
- Повернення незакріпленого профілю до початку використовує коротке системне прокручування замість довгої інерції. Швидкий жест, що доходить до фіксації, продовжує звичайне прокручування.

Локально перевірено зміни коду; компіляція виконується GitHub Actions. Вигляд і жести потребують підтвердження на iPhone. За запитом користувача після запуску збірки робота зупиняється; IPA замінюватиметься окремо.
