# 0.5.9

- Фіксація острівця враховує виміряний центр скла верхніх кнопок та фактичне вертикальне зміщення UISegmentedControl у його системному контейнері.

Компіляція — GitHub Actions; точне вирівнювання на iPhone ще потребує підтвердження.
