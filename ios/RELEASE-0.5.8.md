# 0.5.8 — геометрія та дії «Атмосфери»

- Висота закріплення острівця визначається центром системної навігаційної панелі, як у верхніх кнопок, без додаткового вертикального зміщення від placeholder заголовка.
- У початковому положенні зовнішні краї острівця вирівнюються з крайніми круглими діями. Перед фіксацією ширина плавно пристосовується до вільного місця між верхніми кнопками; контейнер не змінюється.
- Головні рядки прозорі: прибрано окремий матеріал, кольорову підкладку та автоматичне підсвічування фону при зміні стану. Під ними видно справжній фон профілю.
- Зліва зверху — QR-код, справа — олівець із пунктами зміни фото, імені та @нікнейму.
- Імʼя та нікнейм зберігаються локально зі стабільним ID користувача та входять до наявної синхронізації профілю. Порожнє імʼя й зайнятий нікнейм відхиляються; власний поточний нікнейм можна залишити.
- У власному профілі залишено три круглі дії: Студія, Поділитися, Ще. У «Ще» — вихід з акаунта, без дублювання QR-коду, поширення чи зміни фото.

Перевірка компіляції — GitHub Actions. Вирівнювання й жести потрібно підтвердити на iPhone.
