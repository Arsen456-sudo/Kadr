# 0.5.1 — Атмосфера

Студія → Оформлення → Стиль → Атмосфера.

Додатковий стиль профілю: велике фото профілю від верхнього краю, поступовий розмитий перехід у темний фон, імʼя та нікнейм поверх переходу, круглі системні скляні кнопки. Банер у цьому стилі не використовується. Попередні три стилі залишаються доступними.

Кнопка «Фото» відкриває вибір фото й кадрування. Повнорозмірне фото зберігається окремо від невеликої аватарки для стрічки й чатів. Файл включено в резервні копії та майбутню синхронізацію; мережевий режим за замовчуванням вимкнений.

Розмиття фото обчислюється поза головним потоком один раз під час зміни фото. Під час прокрутки змінюються лише геометрія та положення маски.

Перевірка: 11 інтеграційних тестів локального сервера пройшли. Візуальна перевірка на фізичному iPhone ще потрібна.
