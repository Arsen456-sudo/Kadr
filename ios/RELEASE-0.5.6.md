# 0.5.6 — прокрутка й системні переходи

- Острівець «Атмосфери» залишається в одному прозорому контейнері над вмістом. Змінюється тільки позиція; при фіксації він більше не переноситься до іншого батьківського view. Контейнер пропускає всі дотики за межами острівця й ховається при виході з профілю.
- Заголовок «Профіль» зміщується вгору й поступово зникає за ходом останніх 88 пунктів прокрутки перед фіксацією, без окремого таймера чи анімації після порога.
- Шапку профілю відокремлено від секцій публікацій і головних пунктів. Перемикання категорій оновлює тільки ці секції та зберігає круглі кнопки й їхні скляні поверхні.
- Головні пункти перероблено: дві компактні плитки показників і матові рядки бібліотеки, налаштувань та оформлення.
- Для фону аналізуються шість ділянок фото, щоб змішування різних кольорів не давало переважно сірий відтінок. Посилено передачу насиченості й нижній блюр біля імені.
- Кореневі верхні дії використовують справжні UIBarButtonItem та анімовані setLeftBarButtonItems/setRightBarButtonItems. Дочірні екрани залишають власні navigationItem й системний перехід назад. Системні меню, кнопки реакцій, сегменти та вкладки зберігають стандартні обробники UIKit.

Перевірка компіляції — GitHub Actions. Плавність усіх взаємодій і вигляд на пристрої ще потребують перевірки на iPhone; компіляція сама по собі цього не підтверджує.
