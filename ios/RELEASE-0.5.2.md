# 0.5.2

- «Атмосфера»: прогресивне розмиття нижньої частини фото тепер записується безпосередньо в підготовлене зображення через Core Image. Воно більше не залежить від окремої маски шару під затемненням. Верхня частина зберігає роздільність завантаженого фото.
- Стиль профілю застосовується після локальної зміни оформлення, включно зі зміною зі Студії, без перезапуску. Оновлюються заголовок, фото, висота шапки, кнопки й панель інструментів; при зміні стилю прокрутка повертається до початку.
- Обробка розмиття відбувається поза головним потоком один раз при зміні фото або стилю. Запізнілий результат попереднього фото ігнорується.

Візуальне підтвердження на фізичному iPhone потрібне після встановлення IPA.
