# Кадр

## Android

Перша нативна Android-версія написана на Kotlin і Jetpack Compose з офіційними компонентами Material 3 Expressive. Основні сценарії працюють локально; клієнт підготовлений до спільного API з iOS. Докладні можливості, обмеження та команди збірки — в [android/README.md](android/README.md).

Workflow [Android APK](https://github.com/Arsen456-sudo/Kadr/actions/workflows/android.yml) збирає встановлюваний APK в артефакт **Kadr-Android-APK**. Локальний готовий файл: `android/build/apk/Kadr-android.apk`. Потрібен Android 8.0 або новіший.

## iOS

Офлайн-прототип стрічки коротких відео для iPhone з iOS 26 або новішою. Інтерфейс працює на UIKit. «Стрічка», «Збережене», «Вхідні» й «Профіль» використовують штатну навігацію вкладок. У верхньому скляному острівці активний сегмент використовує конфігурацію кнопки UIKit Liquid Glass. Одна верхня кнопка відкриває пошук або виконує вихід з активного профілю.

- Гість може дивитися й гортати вбудовані ролики та читати коментарі.
- Локальний акаунт відкриває лайки, коментарі, збережене, підписки та публікацію відео з галереї. Онбординг пропонує вибрати фото, ввести унікальний `@нікнейм` та ім’я. Реєстр нікнеймів працює в межах пристрою й ігнорує регістр.
- Профіль показує банер, фото, ім’я, нікнейм, опис і власні публікації. Пошук знаходить локальні профілі за нікнеймом. Підписки й збережені відео належать активному акаунту.
- Стрічка «Для тебе» піднімає відео з підписок. Два демонстраційні ролики доступні всім акаунтам, їхній порядок залежить від акаунта.

## Збірка

GitHub Actions генерує проєкт XcodeGen і збирає застосунок на `macos-26`. Після успішного запуску workflow **iOS simulator build** шукай артефакт **Kadr-iOS-Simulator**. Він містить `Kadr-iOS-Simulator.zip` із застосунком для симулятора. Для фізичного iPhone є окрема [збірка підписаного IPA](ios/ci/README.md).

На Mac із Xcode та XcodeGen можна виконати `xcodegen generate --spec ios/project.yml`, відкрити `ios/Kadr.xcodeproj` і запустити схему **Kadr** на симуляторі iPhone з iOS 26+.

Для ручної перевірки пропусти реєстрацію, прогорни два відео й натисни на серце. Створи акаунт, постав лайк, напиши коментар і перезапусти застосунок. Вийди через профіль, перевір, що регістр не дозволяє повторно використати той самий нікнейм, і створи інший акаунт. Перший коментар має бути видимим під відео, а стан лайка нового акаунта має бути порожнім.

## Наступний етап

Перший хмарний етап — Supabase Auth із входом через Google або Apple, глобальна унікальність нормалізованого нікнейма в PostgreSQL та завантаження й відтворення через Cloudflare Stream. Android-клієнт зможе працювати з тим самим API. Локальні профілі й дані поточного прототипу зберігаються в контейнері iOS.
